プライバシーポリシー

このページは、空き日程抽出ツールのWebブラウザ版（以下「本ツール」）が、 Googleアカウントから受け取る情報をどのように扱うかを説明するものです。

運営者：隠れ家クロウラ
制定日：2026年11月9日
改定日：2026年11月15日

English version

1. 本ツールが読み取る情報

本ツールは、Googleでログインした利用者の許可を得て、Google Calendar APIから次の情報を読み取ります。

  • 利用者が所有するカレンダーの一覧（カレンダー名、ID、メインのカレンダーかどうか）
  • それらのカレンダーの、指定した期間の予定（タイトル、開始・終了日時、キャンセル済みかどうか、予定の種類、「空き時間」として扱う設定、利用者自身の出欠の返答）
  • ログイン中のアカウントを画面に表示するための、メインカレンダーのID（通常はメールアドレス）

求める権限は次の2つだけです。いずれも読み取り専用で、予定の作成・変更・削除はできません。

  • https://www.googleapis.com/auth/calendar.calendarlist.readonly
  • https://www.googleapis.com/auth/calendar.events.owned.readonly

2. 情報の使い方

読み取った情報は、指定した期間のうち予定が空いている日を判定し、画面に表示するためだけに使います。 判定はすべて利用者のブラウザの中で行います。

予定のタイトルや具体的な時刻が画面に表示されるのは、利用者がデバッグ表示をONにした場合だけです。

3. 情報の送信と共有

本ツールが通信するのは、Googleのログイン（Google Identity Services）とGoogle Calendar APIだけです。 読み取った情報を運営者や第三者のサーバーへ送信することはなく、販売・共有もしません。 アクセス解析や広告のツールも使っていません。

本ツールのページはGitHub Pagesで配信しています。ページを開いた際の通信記録（IPアドレスなど）は、 配信元のGitHubが同社のプライバシーステートメントに従って扱います。運営者はこの記録を受け取りません。

4. 情報の保存

  • ログインで得たアクセストークンは、ページを開いている間だけブラウザのメモリに置き、保存しません。
  • 予定の内容は保存しません。ページを閉じるか再読み込みすると消えます。
  • 昼・夜の時間設定と、除外するカレンダーのIDは、次回も使えるよう利用者のブラウザ（localStorage）に保存します。このデータはブラウザの外へ送信されず、ブラウザのサイトデータを削除すると消えます。

5. 情報の保護

  • 本ツールには運営者のサーバーがありません。Googleアカウントから受け取った情報が運営者のもとに届くことはなく、運営者が保管することもありません。
  • ページの配信と、GoogleのログインおよびGoogle Calendar APIとの通信は、すべてHTTPS（TLS）で暗号化されます。
  • ページにはコンテンツセキュリティポリシー（CSP）を設定し、読み込めるスクリプトを本ツール自身のものとGoogleのログイン用のものに、通信先をGoogleのログインとGoogle APIのサーバーに限っています。
  • アクセストークンはブラウザのメモリにだけ置き、ストレージやCookieには保存しません。ページを閉じると消え、Googleが定める有効期限（通常1時間）を過ぎると使えなくなります。
  • 求める権限は読み取り専用の2つだけで、予定を作成・変更・削除することはできません。
  • ソースコードはGitHubで公開しており、誰でも処理の内容を確かめられます。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、 限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

7. アクセス権の取り消し

本ツールへのアクセス権は、 Googleアカウントのサードパーティ接続の管理ページ からいつでも取り消せます。

8. お問い合わせ

本ポリシーや本ツールに関するお問い合わせは、 GitHubのIssue からお願いします。セキュリティに関する報告は、 脆弱性の報告フォーム をご利用ください。

9. 改定

本ポリシーを改定する場合は、このページで内容と改定日をお知らせします。 改定の履歴は GitHubのコミット履歴 で確認できます。

Privacy Policy (English)

This page explains how the web version of 空き日程抽出ツール (Free Date Finder, "the app") handles information received from your Google Account. If this English version and the Japanese version above differ, the Japanese version prevails.

Operator: 隠れ家クロウラ (Kakurega Kuroura)
Effective: November 9, 2026 / Last updated: November 15, 2026

1. Data the app accesses

With your permission after you sign in with Google, the app reads the following from the Google Calendar API:

  • The list of calendars you own (calendar name, ID, and whether it is your primary calendar)
  • Events on those calendars within the date range you choose (title, start and end time, whether cancelled, event type, whether the event is marked as "free", and your own response to the invitation)
  • The ID of your primary calendar (usually your email address), to show which account is signed in

The app requests only these two scopes. Both are read-only; the app cannot create, change or delete events.

  • https://www.googleapis.com/auth/calendar.calendarlist.readonly
  • https://www.googleapis.com/auth/calendar.events.owned.readonly

2. How the data is used

The data is used only to determine which days in the chosen range are free and to show them on the screen. All processing happens inside your browser. Event titles and exact times appear on the screen only when you turn on the debug view.

3. Data sharing and transfer

The app communicates only with Google Sign-In (Google Identity Services) and the Google Calendar API. It never sends the data it reads to the operator or to any third party, and never sells or shares it. The app uses no analytics or advertising tools.

The pages are served by GitHub Pages. Access logs created when you open a page (such as IP addresses) are handled by GitHub under its privacy statement. The operator does not receive these logs.

4. Data retention and deletion

  • The access token obtained at sign-in is kept only in browser memory while the page is open, and is never stored.
  • Event data is never stored. It is gone when you close or reload the page.
  • Your daytime and nighttime settings and the IDs of calendars you exclude are saved in your browser's localStorage so they can be reused next time. This data never leaves your browser and is deleted when you clear the site data in your browser.

5. Data protection

  • The app has no server of its own. Data received from your Google Account never reaches the operator and is never kept by the operator.
  • Page delivery and all communication with Google Sign-In and the Google Calendar API are encrypted with HTTPS (TLS).
  • The pages set a Content Security Policy (CSP) that allows only the app's own scripts and Google's sign-in script, and limits connections to Google Sign-In and Google API servers.
  • The access token is kept only in browser memory, never in storage or cookies. It is discarded when you close the page and expires after the period set by Google (usually one hour).
  • The app requests only two read-only scopes and cannot create, change or delete events.
  • The source code is public on GitHub, so anyone can check what the app does.

6. Compliance with the Google API Services User Data Policy

The app's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

You can revoke the app's access at any time on the third-party connections page of your Google Account.

8. Contact

For questions about this policy or the app, please use GitHub Issues. To report a security issue, please use the vulnerability report form.

9. Changes

If this policy changes, the new content and date will be posted on this page. The history of changes is available in the GitHub commit history.
