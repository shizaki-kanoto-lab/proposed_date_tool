プライバシーポリシー

このページは、空き日程抽出ツールのWebブラウザ版（以下「本ツール」）が、 Googleアカウントから受け取る情報をどのように扱うかを説明するものです。

運営者：隠れ家クロウラ
制定日：2026年11月9日

1. 本ツールが読み取る情報

本ツールは、Googleでログインした利用者の許可を得て、Google Calendar APIから次の情報を読み取ります。

  • 利用者が所有するカレンダーの一覧（カレンダー名、ID、メインのカレンダーかどうか）
  • それらのカレンダーの、指定した期間の予定（タイトル、開始・終了日時、キャンセル済みかどうか、予定の種類、「空き時間」として扱う設定、利用者自身の出欠の返答）
  • ログイン中のアカウントを画面に表示するための、メインカレンダーのID（通常はメールアドレス）

求める権限は次の2つだけです。いずれも読み取り専用で、予定の作成・変更・削除はできません。

  • https://www.googleapis.com/auth/calendar.calendarlist.readonly
  • https://www.googleapis.com/auth/calendar.events.owned.readonly

2. 情報の使い方

読み取った情報は、指定した期間のうち予定が空いている日を判定し、画面に表示するためだけに使います。 判定はすべて利用者のブラウザの中で行います。

予定のタイトルや具体的な時刻が画面に表示されるのは、利用者がデバッグ表示をONにした場合だけです。

3. 情報の送信と共有

本ツールが通信するのは、Googleのログイン（Google Identity Services）とGoogle Calendar APIだけです。 読み取った情報を運営者や第三者のサーバーへ送信することはなく、販売・共有もしません。 アクセス解析や広告のツールも使っていません。

本ツールのページはGitHub Pagesで配信しています。ページを開いた際の通信記録（IPアドレスなど）は、 配信元のGitHubが同社のプライバシーステートメントに従って扱います。運営者はこの記録を受け取りません。

4. 情報の保存

  • ログインで得たアクセストークンは、ページを開いている間だけブラウザのメモリに置き、保存しません。
  • 予定の内容は保存しません。ページを閉じるか再読み込みすると消えます。
  • 昼・夜の時間設定と、除外するカレンダーのIDは、次回も使えるよう利用者のブラウザ（localStorage）に保存します。このデータはブラウザの外へ送信されず、ブラウザのサイトデータを削除すると消えます。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、 限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

6. アクセス権の取り消し

本ツールへのアクセス権は、 Googleアカウントのサードパーティ接続の管理ページ からいつでも取り消せます。

7. お問い合わせ

本ポリシーや本ツールに関するお問い合わせは、 GitHubのIssue からお願いします。セキュリティに関する報告は、 脆弱性の報告フォーム をご利用ください。

8. 改定

本ポリシーを改定する場合は、このページで内容と改定日をお知らせします。 改定の履歴は GitHubのコミット履歴 で確認できます。
