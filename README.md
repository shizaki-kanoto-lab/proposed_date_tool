# 空き日程抽出ツール

Google Calendarの予定を確認し、日程調整ツールの候補日として設定する日程を自動で抽出するツールです。
指定した期間の予定を確認し、昼または夜のどちらか一方でも空いている日を一覧として出力します。

次の2つの方法で使えます。判定の規則は同じです（違いは「Apps Script版との違い」を参照）。

| 方法 | 使い始め方 |
|---|---|
| Webブラウザ版（GitHub Pages） | URLを開いてGoogleでログインするだけ |
| Google Apps Script版 | 自分のApps Scriptプロジェクトにファイルを配置してデプロイする |

## 主な機能

- Google Calendarから予定を取得
- 昼・夜それぞれの予定状況を判定
- 日程調整ツールへ貼り付けやすい形式で日付を出力
- 判定する時間帯を変更可能
- 判定から除外するカレンダーを指定可能
- 「ToDo リスト」を常に除外
- デバッグ表示による詳細な判定確認
- 検索期間は最大180日

## 判定条件

初期設定では、以下の時間帯を確認します。

- 昼：13:00〜18:00
- 夜：21:00〜24:00

判定は次のルールで行います。

| 昼 | 夜 | 判定 |
|---|---|---|
| 予定なし | 予定なし | 対象 |
| 予定あり | 予定なし | 対象 |
| 予定なし | 予定あり | 対象 |
| 予定あり | 予定あり | 対象外 |
| 終日予定あり | - | 対象外 |

対象時間帯に重なっている予定のみ判定に使用します。

時間帯外の予定は判定に影響しません。

## Webブラウザ版の使い方

1. https://shizaki-kanoto.is-a.dev/proposed_date_tool/ を開く
2. 「Googleでログイン」を押し、使うGoogleアカウントを選ぶ
3. カレンダーの読み取りを許可する
4. 以降は「使い方」と同じ手順で操作する

ログイン時に「このアプリは Google で確認されていません」という警告が表示されることがあります。続ける場合は「詳細」から先へ進んでください。

### Webブラウザ版で読み取る情報

求める権限は次の2つだけです。予定の作成・変更・削除はできません。

- カレンダーの一覧の読み取り（`calendar.calendarlist.readonly`）
- 自分が所有するカレンダーの予定の読み取り（`calendar.events.owned.readonly`）

### Webブラウザ版の仕組み

- 予定の取得と判定は、すべて利用者のブラウザの中で行います。
- 通信先はGoogleのログインとGoogle Calendar APIだけです。予定をこのリポジトリの管理者や他のサーバーへ送ることはありません。アクセス解析も使っていません。
- ログインの情報（アクセストークン）はブラウザのメモリにだけ置き、保存しません。ページを閉じたり再読み込みしたりするとログインし直しになります。
- 時間設定と除外するカレンダーの設定は、Apps Script版と同じくブラウザに保存されます。

### 利用規約とプライバシーポリシー

- 利用規約：https://shizaki-kanoto.is-a.dev/proposed_date_tool/terms.html
- プライバシーポリシー：https://shizaki-kanoto.is-a.dev/proposed_date_tool/privacy.html

### Apps Script版との違い

- Googleカレンダーの「勤務場所」は判定に使いません。毎日が終日予定として対象外になるのを避けるためです。デバッグ詳細には表示されます。

### 開発者向け

```bash
npm test
npm run serve
```

`npm test` は架空の予定データで判定を確かめ、Apps Script版（`src/Code.js`）と同じ結果になるかも比べます。`npm run serve` は `web/` を http://localhost:8000 で表示します。`main` の `web/` が変わると、テストが通った場合だけGitHub Pagesに公開されます。

## Apps Script版

### 必要なもの

- Googleアカウント
- Google Calendar
- Google Apps Script

### 導入方法

#### 1. ファイルを取得

このリポジトリの `src/` フォルダにある以下のファイルを取得します。

- `Code.js`
- `index.html`
- `appsscript.json`

#### 2. Google Apps Scriptプロジェクトを作成

Google Apps Scriptで新しいプロジェクトを作成します。

既存のコードがある場合は、必要に応じて削除してからファイルを配置してください。

#### 3. ファイルを配置

取得したファイルをApps Scriptプロジェクトに配置します。

- `Code.js`
- `index.html`
- `appsscript.json`

#### 4. Webアプリとしてデプロイ

Apps Scriptの「デプロイ」から「新しいデプロイ」を選択し、Webアプリとしてデプロイします。

初回利用時には、Google Calendarへのアクセス権限を求められます。

画面の指示に従って権限を許可してください。

## 使い方

1. Webアプリを開く
2. 開始日と終了日を指定
3. 必要に応じて時間設定を変更
4. 除外するカレンダーを選択
5. 「予定を取得」をクリック
6. 表示された日付をコピー
7. 日程調整ツールへ貼り付け

## 時間設定

時間帯は30分単位で変更できます。

初期値：

- 昼：13:00〜18:00
- 夜：21:00〜24:00

設定はブラウザに保存され、次回利用時にも引き継がれます。

## カレンダーについて

判定対象となるのは、Googleアカウントが所有しているカレンダーです。

画面からカレンダーを指定して、予定判定から除外できます。

以下は対象外となります。

- 除外設定したカレンダー
- 「ToDo リスト」
- 所有していないカレンダー（購読しているカレンダーなど）

「ToDo リスト」は常に除外されます。

## デバッグ機能

「デバッグ表示をONにする」を有効にすると、各日の判定結果を確認できます。

さらに「詳細を見る」から、

- その日の予定
- 終日予定の有無
- 昼の判定に使用された予定
- 夜の判定に使用された予定
- 対象カレンダー

などを確認できます。

判定結果が意図したものにならない場合の確認に利用できます。

## 検索期間

検索できる期間は最大180日です。

長期間の検索による処理負荷を抑えるため、180日を超える範囲は指定できません。

## Google Calendarのデータについて

Apps Script版は、利用者自身のGoogle Apps Scriptから、利用者自身のGoogle Calendarを読み取って予定を判定します。Webブラウザ版は、利用者のブラウザから利用者自身のGoogle Calendarを読み取って判定します。

このリポジトリの管理者が利用者のカレンダーを閲覧する仕組みではありません。

利用時にはGoogleからCalendarへのアクセス権限を求められます。

不要になった場合は、Googleアカウントの権限設定からアクセス権を削除できます。

## 注意事項

- Google Apps ScriptやGoogle Calendar APIの仕様変更などにより動作しなくなる場合があります。
- Google Calendarの予定情報を読み取るため、適切な権限の許可が必要です。
- 検索期間は最大180日です。
- このツールによる日程判定の結果は、最終的に利用者自身で確認してください。
